    OIOIC，简称 OIC，是我个人专为 C 语言设计的全新而优秀的软件对象模型。

    OIOIC 是非常优秀的，以至于我禁不住“狂言”几句：完美填补 C 语言面向对象技术空白，完美解决软件界多重继承难题，完美对象化对象多线程访问控制，统一软件世界组件规范，统一软件世界代码树结构，统一软件世界面向对象编程思想，统一软件世界高级程序设计语言 ------ OIOIC 使 C 语言成为首选。

    很高兴能把第二版《 OIOIC 入门教程 》呈献给大家！新版除了在内容上有所变化外，还增设了英文版。内容变化主要是用 1.0.6 版的 OIOIC 和 oicc 重新构建了第二、第三、第四章的示例代码。在英文版中，由于本人英文水平有限，部分文字表达可能不妥，欢迎指正！
