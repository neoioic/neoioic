Chapter 7 :   Summary


    The first chapter presented the basic principles of OIOIC and terms & concepts; the diagram gave you the preliminary perceptual knowledge to an Operation System and a Software System that base entirely on OIOIC. In the second chapter, the main purpose is to know well the code tree structure of an OIOIC program. In the third and the fourth chapters, we learned how to use OIOIC to design a single and a multiple inheritance programmes. The fifth chapter illustrated summarily that OIOIC perfectly has achieved the mechanism of arbitrary complex inheritance of class. The sixth chapter narrated suggestively that OIOIC perfectly has objectivized multithreading access control of object.
