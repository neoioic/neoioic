# oicc

这是上游发布的 OIOIC 1.0.18 构造工具：`windows/oicc.exe` 用于 Windows，`linux/oicc` 用于 Linux。上游未提供工具源码，因此它们不能用本仓库的 GCC 构建重建。

这些二进制不参与核心库或示例构建。Linux 文件来自原始发行包，具体架构及运行依赖需要在目标系统确认；必要时先赋予执行权限。

工具会创建节点、读取 `<ibn>` 标记检查继承关系、改写 `<crt>` 区域。查看帮助使用 `-h`；运行可能覆盖构造代码，应先在临时工作副本中操作并检查差异。

当前示例已迁移结果码、公共头文件位置和内存对齐，并采用 Linux 风格命名。原工具不会自动理解这些改动；生成后需要将扩展成员尺寸改为 `OIOIC_ALIGNED_SIZE(struct em_xxx)`、分配计算改为 `size_t`，并核对当前 API、包含路径和失败清理。生成的 `OBJECT`、`VR`、`CRT_XXX`、`TOG_XXX` 等名称也要替换为当前结构体类型和小写命名，见[代码风格与 API 对照](../../docs/coding-style.md)。默认构建直接使用已迁移的构造代码。
