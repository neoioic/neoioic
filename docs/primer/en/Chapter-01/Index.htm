Chapter 1 :   What OIOIC?


Philosophical Thinking

    We are describing the world in software, the quality of our software product is the fidelity that it describes the object.
    An entity's ability to cope with the effect that the outside acts on it, rests with the entity own structure and the time & space which the outside gives it.

  1. An entity is born.
  2. The entity absorbs substances, such as energy absorption, organisms eating.
  3. The entity releases substances, such as energy release, organisms excretion.
  4. Entities interact.
  5. The entity died.
  1. Create an object.
  2. The object absorbs data stream.
  3. The object releases data stream.
  4. Objects interact.
  5. Destroy the object.

Terms and concepts

  1. O or o, OB or ob, OBJ or Obj :  In the time of no dissension, generally refers to Object.
  2. OM or M :  Object Mold.
  3. MSN :  M Serial Number, the serial number of object mold.
  4. OID :  the ID of object, OID mustn't be 0.
  5. EM :  Extended Member.
  6. IC :  Inheritance Chain.
  7. Node or ND or N :  the node of IC. There are FND, IND and LND three types of node.
  8. FND :  the first node of IC. An IC must have but just only one FND, namely, OIOIC.
  9. IND :  the inner node of IC. In an IC, apart from FND and LND, other nodes are IND. An IC may have more than one IND, or may not.
  10. LND :  the last node of IC. An IC must have but just only one LND, an IC is born after an object was created, the object is an LND.
  11. BN :  Base Node.
  12. IBN or IB :  Immediate BN.
  13. DN :  Derived Node.
  14. IDN :  Immediate DN.
  15. BO :  Base Object.
  16. DO :  Derived Object.
  17. MO :  Master Object, namely, a processe. (.mo)
  18. CO :  Compile subordinated Object, the object taken in at compile-time, namely, a Static Link Library. (.co)
  19. RO :  Runtime linking Object, the object linked at run-time, namely, a Dynamic Link Library. (.ro)
  20. SO :  Subordinate Object.
  21. AO :  Active Object, only thread can be AO.
  22. GO :  General Object, from AO.
  23. HO :  Host Object, HO is MO or CO or RO.
  24. PO :  Peer Object.
  25. SE :  Subordinate Episome which is subordinate to an object but not to the all SO(s) of the object. For instance, all library functions of the C programming language are OS's SEs, because they don't exclusively belong to any one SO of OS.
  26. PE :  Peer Episome.
  27. CR :  Caller, only AO can be CR.
  28. CE :  Callee, any object can be CE.
  29. CS :  Caller's Seat. The minimum number of CS of a node = the number of CR * ( the number of DN of the longest derivative path of the node + 1 ). If the object has no free CS, then a new CR will be out.
  30. VO :  Visit Object, that is, call an interface of object.
  31. VR :  Visiting Record.
  32. MR :  Mandator, a mandator of CR, an object which consigns the calling CR to visit another object. MR does not have transitivity, for example, object A consigns object B to visit object C, then for C, A is the MR of B, if C let B visit object D during the visiting of B to C, then for D, C is the MR of B, but A isn't the MR of B.
  33. TOG :  the function toggling object's interfaces, shortening to TOG function.
  34. CRT :  the function creating object, shortening to CRT function.
  35. ACS :  the Array of CS, the type of element is VR.
  36. AND :  the Array of ND of IC, the type of element is OBJECT, the number of element is the number of IC's ND. The first element of AND must be LND, otherwise the array is not AND.
  37. ABN :  the Array of BN, the type of element is OBJECT*.
  38. AIB :  the Array of IB, the type of element is OBJECT*. The order of visiting IB is from first to last.
  39. IRF :  Interface Result Function, viz. a function whose return type is IRESULT. For good readability, suggest that the IRF function's name be prefixed by "IRF_".
  40. DNG buffer :  Dangerous buffer. In order to economize memory space, can define a multi-purpose shared memory buffer, we call it DNG buffer if there are risks because it is multifunctional, even though it is finally confirmed that these risks had been removed.
  41. DNG function :  Dangerous function, that is a function using DNG buffer. For good readability, suggest that the DNG function's name be prefixed by "DNG_".

The schematic drawing of the new generation Operation System Oicos based entirely on OIOIC


    All black dots are SEs; all circles, including the big circle Oicos, are objects.

The schematic drawing of the new generation computer software system based entirely on OIOIC


    Each ball is an object, the first ball is a booting system (Booter), other balls are the Operation System (OS), a computer can simultaneously run multiple OSs. The Booter is a very small object, which is firstly created after the hardware system is powered on, thus the first OIOIC object is born. Each OS is created by the Booter, also, the Booter implements the switching between OSs. If you would like to know what type objects are Booter and OS, should find the answer in the Hardware World.
