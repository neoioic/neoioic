第一章  认识 OIOIC


一、哲学思考

    我们在用软件描述这个世界，我们的软件产品的质量就是这个软件对它所描述对象的逼真度。
    实体对外界对它作用的应对能力取决于其自身的构造和外界给予它的时间与空间。

  1. 实体产生。
  2. 实体吸收物质，比如吸收能量、生物体进食。
  3. 实体释放物质，比如释放能量、生物体排泄。
  4. 实体与实体之间互相作用。
  5. 实体消亡。
  1. 创建对象。
  2. 对象吸收数据流。
  3. 对象释放数据流。
  4. 对象与对象交互。
  5. 销毁对象。

二、名词概念

  1. O 或 o，OB 或 ob，OBJ 或 Obj ：在没有歧义的情况下，一般都指 Object，即对象。
  2. OM 或 M ：Object Mold，对象模。
  3. MSN ：M Serial Number，对象模的序号。
  4. OID ：对象的 ID。对象的 OID 不能为 0。
  5. EM ：the Extended Member，扩展成员。
  6. IC ：Inheritance Chain，继承链。
  7. Node 或 ND 或 N ：the NoDe of IC，继承链节点。节点有 FND、IND、LND 三种。
  8. FND ：First ND，继承链的首节点。一条 IC 有且只有一个 FND，这个 FND 就是 OIOIC。
  9. IND ：Inner ND，继承链的内节点。一条 IC 除了 FND 和 LND 以外其它节点都是 IND。一条 IC 可能有多个 IND，也可能没有 IND。
  10. LND ：Last ND，继承链的末节点。一条 IC 有且只有一个 LND，创建一个对象就产生一条 IC，这个对象就是 LND。
  11. BN ：Base Node，基节点。
  12. IBN 或 IB ：Immediate BN，直接基节点。
  13. DN ：Derived Node，派生节点。
  14. IDN ：Immediate DN，直接派生节点。
  15. BO ：Base Object，基对象。
  16. DO ：Derived Object，派生对象。
  17. MO ：Master Object，宿主对象，即进程。（.mo）
  18. CO ：Compile subordinated Object，编译时收纳的对象，即静态库。（.co）
  19. RO ：Runtime linking Object，运行时链接的对象，即动态库。（.ro）
  20. SO ：Subordinate Object，从属对象。
  21. AO ：Active Object，活动对象。只有线程是 AO。
  22. GO ：General Object，一般对象，区别于 AO。
  23. HO ：Host Object，主对象。MO，CO，RO 就是 HO。
  24. PO ：Peer Object，同级对象。
  25. SE ：Subordinate Episome，从属游离体，即从属于某对象但游离于这个对象的所有 SO 之外的个体。比如，C 语言的库函数就是 OS 的 SE，因为它们不专属于 OS 里的任何 SO。
  26. PE ：Peer Episome，同级游离体。
  27. CR ：CalleR，来访者。只有 AO 才能做 CR。
  28. CE ：CalleE，受访者。任何对象都可做 CE。
  29. CS ：Caller's Seat，来访者的坐位。节点的最少 CS 数量 = CR 数量 *（该节点最长派生路径的 DN 数量 + 1）。如果对象已没有空闲的 CS，那么新来的 CR 将被“拒之门外”。
  30. VO ：Visit Object，访问对象，即调用对象的接口。
  31. VR ：Visiting Record，来访记录。
  32. MR ：MandatoR，CR 的委托者，即委托来访的 CR 去访问另一对象的对象。MR 不具有传递性，比如，对象 A 委托对象 B 去访问对象 C，那么对 C 来说 A 是 B 的 MR，如果在 B 访问 C 期间 C 又让 B 去访问 D，那么对 D 来说 C 是 B 的 MR，但 A 不是 B 的 MR。
  33. TOG ：the function TOGgling object's interfaces，关联对象接口的函数，简称 TOG 函数。
  34. CRT ：the function CReaTing object，创建对象的函数，简称 CRT 函数。
  35. ACS ：the Array of CS，ND 的 CS 数组，数组元素类型是 VR。
  36. AND ：the Array of ND of IC，IC 的 ND 数组，数组元素类型是 OBJECT，元素数量就是 IC 的 ND 数量。AND 的第一个元素必须是 LND，否则不能称为 AND。
  37. ABN ：the Array of BN，BN 数组，数组元素类型是对象指针。
  38. AIB ：the Array of IB，IB 数组，数组元素类型是对象指针。访问 IB 的顺序是从第一个到最后一个元素。
  39. IRF ：Interface Result Function，接口结果函数，即返回值类型是 IRESULT 的函数。为了便于区别，IRF 的函数名前最好有前缀 “IRF_”。
  40. DNG缓冲 ：DaNGerous buffer，危险缓冲。为了节省内存空间，可以开辟一块多处共用的缓冲，如果这块缓冲因多处公用而存在风险，那么这样的缓冲就叫 DNG 缓冲，即使这些风险最终确定已经消除。
  41. DNG函数 ：DaNGerous function，危险函数，也就是使用 DNG 缓冲的函数。为了便于区别，DNG 函数名前最好有前缀 “DNG_”。

四、完全基于 OIOIC 的计算机软件系统示意图


    每个球都是对象，第一个小球是引导器（Booter），其它球是操作系统（OS），一台计算机可以同时跑多个 OS。Booter 是个很小的对象，硬件系统上电后首先创建它，这样就产生了第一个 OIOIC 对象。每个 OS 都由 Booter 创建，OS 间的切换也由 Booter 执行。如果想知道 Booter 和 OS 是什么类型的对象，应该到硬件世界里找答案。
