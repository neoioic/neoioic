Chapter 5 :   Arbitrary Complex Inheritance Chain


 OIOIC perfectly supports arbitrary complex inheritance chain, completely solved the multiple inheritance problem in the Software World.




 There is no code examples in this chapter, you can define your own requirement, then practise to design it with OIOIC.
 An inheritance chain can be arbitrary complex, but its inheritance relationship must be valid. If a chain's inheritance relationship is invalid, while constructing, the oicc will prompt the "repetitive inheritance.(node name)" error that means: there is a repetitive inheritance relationship in the inheritance chain whose LND is the "node name".
